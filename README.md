# Beauty Brand Competitive Analysis & Benchmarking

## 📌 Project Overview
This project analyzes and compares five beauty brands using Microsoft Excel and Power BI. It explores customer ratings, product pricing, sentiment analysis, and improvement opportunities through interactive dashboards and data visualization.

## 🎯 Objectives
- Compare the performance of five beauty brands.
- Analyze customer ratings and sentiment distribution.
- Understand product pricing across brands.
- Identify key customer feedback and improvement areas.
- Present actionable insights through an interactive dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Excel** – Data cleaning and preparation
- **Microsoft Power BI** – Dashboard development and visualization
- **Data Analysis** – Brand benchmarking and customer sentiment analysis

## 📊 Key Analysis
- Brand-wise average ratings
- Customer sentiment distribution
- Average product price comparison
- Product category analysis
- Price versus rating analysis
- Customer feedback and improvement opportunities

## 💡 Key Benefits
- Provides a clear comparison of beauty brand performance.
- Helps identify customer preferences and satisfaction patterns.
- Highlights potential areas for product and service improvement.
- Supports data-driven business decisions.

## 📁 Project Files
- `README.md` – Project documentation

- Dataset (`.xlsx` or `.csv`)
- Dashboard screenshots

## 📌 Data Disclaimer
This project uses sample data for educational and analytical purposes. The findings should not be interpreted as verified real-world customer opinions or official brand performance.
